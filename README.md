# ML-HEP

Machine learning studies and tools for **High Energy Physics (HEP)**.

This repository contains machine learning work arising from HEP analyses, including problems encountered during my own analyses as well as other ML applications relevant to HEP.

The repository may include studies involving:

- Boosted Decision Trees (BDTs)
- XGBoost
- Classification
- Feature engineering
- ML-based analysis techniques

This is a collection of ongoing HEP/ML work rather than a standalone framework.
